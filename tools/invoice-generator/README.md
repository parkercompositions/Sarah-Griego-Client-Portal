# Invoice Generator

Reproduces Sarah's exact invoice template (measured from her original PDF).

- `make_invoice.py` — the generator script (reportlab)
- `fonts/` — RockSalt-Regular, Poppins Regular/Light/SemiBold
- `signature.png` — signature image with transparency

This lives on the `tools` branch, not `main`, so it is never deployed to the live client portal site.
